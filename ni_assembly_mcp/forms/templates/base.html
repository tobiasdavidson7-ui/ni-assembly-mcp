An unofficial interface to the Northern Ireland Assembly Open Data API. Official Report (Hansard) search additionally builds on data from TheyWorkForYou (mySociety): data service provided by TheyWorkForYou. Debate text is under the Open Parliament Licence / the Assembly's own Official Report reuse terms; speaker identifiers are CC BY-SA 2.5.

This site is not affiliated with the Northern Ireland Assembly or with mySociety / TheyWorkForYou. It never sends your queries to any language model.

This isn't the only way to explore the Assembly's public data — other sites cover votes and activity stats well. This one focuses on searching the actual content of what's said and asked: debates, questions, answers and motions. The same data is also available as an MCP tool, so an AI assistant can query it directly — see connect your client for that option.
