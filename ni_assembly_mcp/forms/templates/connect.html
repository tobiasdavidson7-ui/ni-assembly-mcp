Connect your own MCP client

Point any HTTP-capable MCP client — Claude Desktop, Claude Code, or your own agent — at this server and use its tools with your language model. This server only answers Assembly data queries: it never handles your LLM calls, your prompts or your API key.

New to this? Connect Claude or ChatGPT in a few clicks

This lets you ask questions in plain English — “Which MLAs have asked about mental health funding this year?” — and get answers pulled directly from official records, instead of filling in forms yourself. You're not uploading anything or giving away any personal data; you're just letting your assistant ask this site's forms for you. No login is required and no queries are ever sent to a language model by this site itself.

{{ mcp_url }}

Claude (claude.ai or Claude Desktop)

  1. Open Claude and go to Settings → Connectors (sometimes labelled “Integrations” or “MCP Servers”, depending on your version).
  2. Choose Add custom connector (or “Add connector”).
  3. Paste in the address above.
  4. Give it a name, e.g. “NI Assembly Data”.
  5. Save. You may be asked to approve the connection the first time you use it.
  6. Start a new chat and just ask your question naturally — Claude will use the connector automatically when it recognises the question needs this data.

ChatGPT or other MCP-compatible assistants

Support varies by provider and changes often, so the exact menu names may differ:

  1. Look for a setting called Connectors, Plugins, or Tools in your assistant's settings.
  2. Look for an option to add a custom MCP server or remote tool.
  3. Enter the same address as above.
  4. Save and start a new conversation to test it.

If your assistant doesn't support custom MCP connectors yet, you can still use the plain forms — no functionality is lost, it's just a manual process rather than a conversational one.

Try asking

  • “Which committees are meeting next week?”
  • “Show me how [constituency]'s MLAs voted on [recent division topic].”
  • “Has the Minister for [department] answered any questions about [topic] this year?”

A few honest caveats

  • The assistant can still make mistakes summarising results — click through to the original record before quoting it in a report or briefing.
  • This connector fetches real official data, but it doesn't fact-check the Assembly's own records — accuracy depends on the underlying NI Assembly Open Data API.
  • No login or personal data is required — the connector only reads public Assembly records.
